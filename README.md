## 📌 โครงการที่ทำการทดสอบ

📱 **ระบบเว็บไซต์แจ้งรายงานความเสียหายประกันภัยข้าว** (Rice Insurance Damage Reporting System) — ด้วย Robot Framework, 2569

มาตรฐานเอกสาร: **IEEE 829-2008** (Test Plan → Test Design → Test Case → Test Execution → Test Report)

- **ขอบเขตการทดสอบ (Testing Scope & Features):**
  - Login & Register Verification
  - Add / Edit / Submit Damage Report
  - Approve / Reject Damage Report Workflow
  - Calculate Claim Amount & Notify Status
- **จำนวน Test Case:** 13 Test Scenario (TC01–TC13) แตกเป็น 34 กรณีทดสอบย่อย ครอบคลุม 4 บทบาทผู้ใช้งาน (เกษตรกร, เจ้าหน้าที่ส่งเสริมการเกษตร, เจ้าหน้าที่ประกันภัย, ผู้ดูแลระบบ)
- **เทคนิคการออกแบบ Test Case:** Equivalence Partitioning, Boundary Value Analysis, Error Guessing, Decision Table, Pairwise Testing
- **User Journey/E2E:** 6 Flow หลัก ครอบคลุมกระบวนการตั้งแต่สมัครสมาชิกจนถึงอนุมัติค่าสินไหมทดแทน
- **สภาพแวดล้อมระบบ (System Environment):** `Robot Framework` , `Excel` , `Word`
